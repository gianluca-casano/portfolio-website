# Personal Portfolio - [Visualizza il sito live](https://gianlucacasano.it/)

Benvenuto nella repository del mio sito web portfolio personale. Questo spazio digitale è stato progettato e sviluppato con l'obiettivo di presentarmi in modo professionale a realtà aziendali come **Junior Web Designer & Front-end Developer**, mostrando le mie competenze, la qualità del mio codice e i miei progetti pratici.

Il sito è strutturato con un'architettura **One-Page**, ottimizzata per offrire una User Experience (UX) fluida, una navigazione scattante e un percorso di conversione immediato per recruiter e lead developer.

---

## Stack Tecnologico & Strumenti

Per lo sviluppo di questo progetto ho scelto di non utilizzare page builder (come Elementor), preferendo un approccio di sviluppo custom basato sulle API native di WordPress per garantire stabilità, pulizia del codice e performance di caricamento eccellenti.

* **UI/UX Design & Prototipazione:** Figma
* **Core CMS & Backend:** WordPress / PHP (Custom Theme basato sullo starter theme *NextFrame* di Andrea Marchetti)
* **Architettura Dati:** Custom Post Types (CPT) & Advanced Custom Fields (ACF)
* **Frontend & Animazioni:** HTML, CSS, JavaScript, GSAP (con l'utilizzo di ScrollTrigger)

---

## Caratteristiche Principali del Progetto

* **Performance & Lightweight:** Architettura custom ridotta all'essenziale per azzerare il peso delle pagine e garantire un caricamento istantaneo.
* **Architettura del Codice:** Sviluppo strutturato e modulare basato sulla gerarchia dei template di WordPress, con file puliti e commentati.
* **Responsive Design:** Interfaccia interamente responsive, sviluppata per adattarsi nativamente a smartphone, tablet e desktop.
* **UX Focalizzata sui Recruiter:** Layout lineare pensato per mettere subito in luce le competenze chiave, i casi studio (come il progetto *Armonis*) e le modalità di contatto rapido.

## Struttura del Tema Custom

Basandosi sull'organizzazione modulare dello starter theme, la repository ospita i file sorgente organizzati come segue:

* `style.css` – Contiene le informazioni ufficiali del tema e le importazioni stilistiche core.
* `functions.php` / `custom-functions.php` – Gestiscono l'inizializzazione delle funzionalità del tema.
* `header.php` / `footer.php` – Componenti globali per la testata e il piè di pagina del sito.
* `index.php` – Configurato come file di fallback blindato con reindirizzamento sicuro alla Home Page per garantire una UX senza errori.
* `404.php` – Pagina di gestione degli errori di navigazione, ottimizzata per riportare l'utente alla Home Page.
* `/custom` – Cartella principale del comparto custom del tema:
  * `custom-template.php` – Il template principale utilizzato per la renderizzazione e la logica della pagina portfolio.
  * `custom-style.css` / `custom-scripts.js` / `bundle.min.js` – Logica di stile, script e ottimizzazione delle performance frontend e delle animazioni GSAP.
  * `home-template.php` – Template predisposto e strutturato per futuri aggiornamenti o varianti di layout dell'interfaccia.
  * `/img` – Risorse visive e asset grafici del sito.
* `/fonts` / `/icons` – Directory dedicate rispettivamente ai font locali e alle icone SVG grafiche del layout.
